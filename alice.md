# Alice Commands

Этот файл описывает команды, которые сейчас поддерживает навык Алисы для `llmstore.pro`.

## Общие команды

- `ping`
  - Ответ: `pong`
- `привет`
- `здравствуй`
- `здравствуйте`
- `начать`
- `старт`
- `авторизоваться`
- `авторизация`
- `войти`
- `вход`
- `войти в аккаунт`
- `подключить аккаунт`
- `привязать аккаунт`
  - Возвращают приветственный или служебный стартовый ответ навыка.

## Справка

- `помощь`
- `помоги`
- `что ты умеешь`
- `что умеешь`
- `что ты можешь`
- `что можешь`
- `какие команды у тебя есть`
- `какие у тебя есть команды`
- `какие команды есть`
- `какие есть команды`
- `кто ты`
- `ты кто`
- `что ты такое`
  - Возвращают короткую справку по возможностям навыка.

## Список команд

- `список команд`
- `покажи список команд`
- `покажи команды`
- `перечень команд`
  - Возвращают явный список доступных команд.

## О сервисе

- `о чём llm store`
- `что такое llm store`
- `что это llm store`
- `что умеет llm store`
- `что можно в llm store`
- `расскажи про llm store`
- `возможности llm store`
  - Возвращают описание сервиса LLM Store.

## Привязка аккаунта через код

- `привяжи аккаунт 123456`
- `привяжи аккаунт 123 456`
- `свяжи аккаунт 123456`
  - Поддерживаются коды длиной от 4 до 8 цифр.
  - Код можно произносить слитно, с пробелами или с дефисами.

## Статус и продолжение ответа

- `уточни статус задачи`
- `уточнить статус`
- `статус задачи`
- `статус последней задачи`
- `статус`
  - Возвращают статус последней задачи и, если ответ уже готов, первую или следующую доступную часть ответа.

- `продолжи ответ`
- `продолжить ответ`
- `следующая часть ответа`
- `продолжение ответа`
  - Возвращают следующую часть последнего длинного ответа.

## Баланс и количество чатов

- `сколько у меня чатов`
- `какой у меня баланс`
- `сколько у меня чатов и какой у меня баланс`
- `сколько у меня денег`
- `сколько у меня на балансе`
  - Возвращают количество чатов, баланс или оба значения сразу.

## Выбор чата

- `какой сейчас чат`
- `какой текущий чат`
- `какой выбран чат`
  - Показывают текущий выбранный чат.

- `открой последний чат`
- `выбери последний чат`
- `переключи на последний чат`
  - Выбирают последний чат.

- `открой первый чат`
- `выбери первый чат`
- `переключи на первый чат`
  - Выбирают первый чат.

- `открой чат номер 3`
- `выбери чат номер 3`
- `переключи на чат номер 3`
  - Выбирают чат по номеру.

- `открой чат Alice`
- `открой чат картинка семена`
- `выбери чат <название>`
- `переключи на чат <название>`
  - Выбирают чат по названию.
  - Для команды выбора по названию навык сразу сообщает, что чат открыт, сколько в нём сообщений, и читает последнее сообщение.

## Чтение сообщений из выбранного чата

- `прочитай первое сообщение`
- `прочитай последнее сообщение`
- `прочитай сообщение 2`
- `прочитай сообщение номер 2`
- `прочитай мой последний вопрос`
- `мой последний вопрос`
- `последний мой вопрос`
- `последний ответ`
- `повтори последний ответ`
- `что ты ответил на мой последний вопрос`
- `ответ на мой последний вопрос`
- `прочитай последние 3 сообщения`
  - Работают относительно текущего выбранного чата.

## Краткий пересказ чата

- `о чем этот чат`
- `о чём этот чат`
- `перескажи этот чат`
  - Возвращают краткое описание выбранного чата, количество сообщений, последний вопрос пользователя и последний ответ ассистента.

## Важные замечания

- После команды `открой чат <название>` следующий запрос на чтение сообщения должен работать уже в этом выбранном чате.
- Длинные ответы могут приходить частями через команды `уточни статус задачи` и `продолжи ответ`.
- Ответы Алисы ограничены лимитами Яндекса, поэтому длинные тексты и код могут делиться на несколько частей.
